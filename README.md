### About

I'm an AI Engineer at Infosys working on agentic AI and Model Context Protocol (MCP) systems. Before that, I built AI software for humanoid robots in Infosys R&D, which taught me to design for reliability first: when an AI system acts in the real world or feeds a business decision, its output has to be checkable.

- 🔧 **Building:** LLM agents with tool-calling loops, structured outputs, and verification steps
- 🔌 **Working with:** MCP servers and clients, multi-platform integrations, evaluation harnesses
- 📚 **Learning:** LangGraph and RAG pipelines
